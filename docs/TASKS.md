## 推荐执行顺序

1. 内置 OCR 执行引擎并在干净环境验证。
2. 做三类真实 PDF 的端到端导入、翻译、导出测试。
3. 完成 DOCX/PDF 视觉保真和异常恢复。
4. 增加持久化、取消、性能与安全发布审计。
5. 最后签名、安装验证并发布。
