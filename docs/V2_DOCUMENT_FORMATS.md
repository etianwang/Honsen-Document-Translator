# v2：多格式文档翻译

## 目标

将 Honsen Document Translator 从 PDF 专用工具扩展为桌面文档翻译器，首批支持 `.pdf`、`.doc`、`.docx`、`.ppt`、`.pptx`、Excel、`.txt` 与 `.md`。用户选择一个源文件后，应用识别格式、展示对应预览与选项、复用术语库和 DeepL 翻译，并输出带目标语言前缀的译文文件。

## v2 交付边界

| 格式族 | 导入 | 译文输出 | 版式策略 |
| --- | --- | --- | --- |
| PDF | `.pdf` | `.pdf`、`.docx` | 复用现有 PDF 版式与 OCR 管线 |
| Word | `.doc`、`.docx` | `目标语言_原名.docx` | `.doc` 先由内置 LibreOffice 转换为 `.docx`；翻译正文、表格、页眉页脚和文本框；批注、修订记录、脚注与尾注原样保留。段落格式不变，不为译文增添段落或句子。 |
| PowerPoint | `.ppt`、`.pptx` | `目标语言_原名.pptx` | `.ppt` 先转换为 `.pptx`；翻译幻灯片、表格、文本框和演讲者备注；保留母版、图表数据标签和 SmartArt。译文先自动缩小、换行，仍放不下则扩大文本框。 |
| Excel | `.xls`、`.xlsx` | `目标语言_原名.xlsx` | `.xls` 先由内置 LibreOffice 转换为 `.xlsx`；仅翻译普通文本单元格，不拆分或重建合并单元格，不修改公式。 `.xlsm` 首版不支持。 |
| 纯文本 | `.txt` | `.txt` | 保留 UTF-8 / UTF-16 编码和换行；其他编码明确提示后不转换 |
| Markdown | `.md`、`.markdown` | `目标语言_原名.md` | 翻译正文、标题、表格单元格、YAML front matter 的值与图片替代文本；保护 YAML 键、代码块、行内代码、链接 URL 与公式 |

不把扫描型 Office 文件、嵌入图片中的文字、复杂 SmartArt、图表数据标签和受密码保护文件列入 v2 的保真承诺；Office 图片 OCR 默认关闭。这些内容应明确提示并保留原样。

## 实现方式

1. 建立 `source-type registry`：按扩展名选取导入器、预览器、导出器与可用选项；UI 只读取该注册表，不在组件内散落格式判断。
2. 建立共享 `TranslationUnit`：所有格式先提取带上下文的可译文本单元，再统一经过术语库、DeepL、保护规则和进度汇报。
3. PDF 继续使用现有 `DocumentModel`、OCR、布局与碰撞校验。
4. Word/PowerPoint/Excel 采用 OOXML 适配器：旧格式先由随应用分发的 LibreOffice 无头转换为 OOXML；以段落/表格单元格/幻灯片文本/工作表文本单元格为单位替换 XML 文本节点，保留既有样式、布局、媒体关系、合并关系和公式。每个适配器产出“已翻译 / 原样保留 / 不支持”的元素报告。
5. TXT/Markdown 使用原生文本适配器：检测 UTF-8/UTF-16 与换行符；Markdown 先标记不可翻译片段，再只向翻译器提交正文片段。
6. UI 采用已确认的 A 版顶部文件类型分页：PDF、Word、演示文稿、Excel、文本/Markdown 五个入口共享语言、术语表、进度和导出区域；选择文件后自动切到识别出的分页。
7. 测试采用每种格式的最小夹具、格式保护断言和导出后重新打开验证；Word/PowerPoint 额外做 LibreOffice PDF 对照与关键页面截图回归。
8. 内嵌预览：Office 源文件与译文均临时转换为 PDF 后复用现有连续 PDF 预览；TXT/Markdown 直接以原编码文本显示。临时预览文件读入后立即清理。

## 导入和样式保护规则

- 每个分页只显示并校验其格式：PDF `.pdf`，Word `.doc/.docx`，演示文稿 `.ppt/.pptx`，Excel `.xls/.xlsx`，文本/Markdown `.txt/.md/.markdown`。文件扩展名不匹配时，导入立即中止并给出明确提示。
- Word 只替换段落内的可译文本，不新增、删除或拆分段落，不修改段落样式、缩进、对齐、编号、表格结构、页眉页脚或文本框格式。
- PowerPoint 只替换既有文本框和表格单元格中的文字，不创建新段落；空间不足依次缩小字体、自动换行、扩大原文本框。
- Excel 仅替换普通文本单元格的内容，公式、合并区域及它们的格式完全不参与翻译或重建。

## 里程碑

1. 文件类型分页、注册表、TXT/Markdown 导入与导出。
2. DOC/DOCX 转换、文本单元提取与回写。
3. PPT/PPTX 转换、幻灯片文本单元提取与回写。
4. Excel 文本单元提取与回写，合并单元格与公式保护。
5. 统一进度、格式能力提示、失败报告与视觉回归。

## 已确认的 UI 决策

使用 A 版：在现有工具栏上方放置文件类型分页。Excel 加入后扩展为五个分页。
