# 主流程实现审查

审查日期：2026-09-28。依据产品 PRD 的“先分析、后确认、再翻译、最后导出”链路执行。

## 已确定的状态机

```text
空白 → 导入中 → 原文审阅 → 翻译中 → 译文审阅 → 导出
```

导入只允许本地读取、PDF 页面分类、文本提取和可选 OCR。它不会创建翻译请求。只有 `原文审阅` 和 `译文审阅` 状态可以启动翻译；只有 `译文审阅` 状态可以导出。取消会回到上一个可继续的审阅状态。

## 约束

不得把未翻译原文写入 `translatedText`，不得在没有译文时导出，也不得因为单个图片对象未就绪而阻塞整个页面。所有新增阶段必须先写状态机测试，再接入 UI。
